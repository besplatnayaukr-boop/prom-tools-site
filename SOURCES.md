Правила пересказаны, а не воспроизведены целиком. Названия кнопок и поведение сверены с editor/editor.html, editor/workflow.js, editor/composition.js, phrases/analysis.js, phrases/app.js, phrases/background.js, analytics/report.js.

H3 — индекс первого появления в сохранённых заголовках, не абсолютная позиция Google. Повторы — не поисковый объём. Подсветка не реализует алгоритм Prom. В справке указано ограничение расстояния между словами. Термин «перестановки» показан отдельно по двум предоставленным скриншотам старого вебинара Prom; на слайде 4 промежуточных слова = 4 перестановки. Видео не доступно для проверки, его URL не выдуман. Для конкретной перестановки слов не заявлено обязательное исключение из выдачи.

CPA в интерфейсе — локально рассчитанный рейтинг (оборот / показы) × 100. В guide объяснено отличие от комиссии. Кнопка 60-10 описана по коду, включая отличие от 60 полных дней без последних 10.

20 иллюстраций заново сверстаны по предоставленным скриншотам. Исходные приватные скриншоты не включены. Все скрытые блоки содержат только искусственные данные. Иллюстрации — SVG с XHTML для переноса текста внутри полей; автономные HTML-версии лежат рядом.

Расширение и его архивы не менялись.
